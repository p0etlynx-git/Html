🔌 Необходимые расширения

  • clangd (от LLVM) - IntelliSense для C/C++
  • C/C++ (от Microsoft) - отключить IntelliSense в настройках
  • Cortex-Debug (от Marus) - отладка STM32
  • STM32 for VS Code (от ST) - работа с CubeMX
  • CMake Tools (от Microsoft) - сборка проектов
  • Assembly - подсветка синтаксиса .s/.asm

Важно!

После установки clangd отключи встроенный IntelliSense от Microsoft:

"C_Cpp.intelliSenseEngine": "Disabled"

Для работы clangd с STM32

Добавь в CMakeLists.txt:

set(CMAKE_EXPORT_COMPILE_COMMANDS ON)

Или используй утилиту bear для Makefile:

bear -- make
