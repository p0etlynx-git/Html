2. Терминал (читаемый шрифт)

Добавь в settings.json (глобальные или проекта):

// ------------------ Терминал ------------------ "terminal.integrated.fontSize": 14, "terminal.integrated.fontFamily": "JetBrains Mono, Consolas, 'Courier New', monospace", "terminal.integrated.lineHeight": 1.2, "terminal.integrated.cursorBlinking": false, "terminal.integrated.cursorStyle": "block", "terminal.integrated.minimumContrastRatio": 4.5, // Для WSL (если используется) "terminal.integrated.shell.windows": "C:\\Windows\\System32\\wsl.exe", // Для Git Bash // "terminal.integrated.shell.windows": "C:\\Program Files\\Git\\bin\\bash.exe"

Совет Если шрифт всё ещё мелкий — увеличь fontSize до 16–18.

3. Сниппеты для C / C++

Файл .vscode/cpp.json (или глобальные):

{ // Цикл for с индексом "For loop": { "prefix": "fori", "body": [ "for (int ${1:i} = 0; ${1:i} < ${2:count}; ${1:i}++) {", "\t${3:// body}", "}" ], "description": "Стандартный цикл for" }, // Обратный цикл "For reverse": { "prefix": "forr", "body": [ "for (int ${1:i} = ${2:size} - 1; ${1:i} >= 0; ${1:i}--) {", "\t${3:// body}", "}" ], "description": "Цикл for в обратном порядке" }, // Include guard для заголовка "Header guard": { "prefix": "ifdefh", "body": [ "#ifndef ${1:HEADER_NAME}_H", "#define ${1:HEADER_NAME}_H", "", "${2:// содержимое}", "", "#endif // ${1:HEADER_NAME}_H" ], "description": "Стандартный include guard" }, // Шаблон main() для embedded "Main embedded": { "prefix": "mainemb", "body": [ "#include ", "#include ", "", "int main(void) {", "\t${1:// Инициализация}", "\t", "\twhile (1) {", "\t\t${2:// Основной цикл}", "\t}", "\t", "\treturn 0;", "}" ], "description": "main() для встроенных систем (бесконечный цикл)" } }

Использование Набери fori в .c/.cpp и нажми Tab — появится шаблон. Перемещайся по полям с помощью Tab.

5. Расширения для embedded

  • PlatformIO — фреймворк для IoT / микроконтроллеров
  • Cortex-Debug — отладка ARM Cortex-M
  • CMake Tools — управление сборкой через CMake
  • Better C++ Syntax — подсветка тем, шаблонов, концептов
  • Doxygen Documentation Generator — автодокументация

6. Тема GND/VCC (быстрый старт)

Создай папку .vscode в проекте, внутри — файл settings.json с этими цветами (или используй готовую тему из Marketplace).

// Фрагмент цветовой схемы "workbench.colorCustomizations": { "[Твоя тема]": { "editor.background": "#1a1a1a", "editor.foreground": "#d4d4d4", "editorCursor.foreground": "#f0a030", "editor.selectionBackground": "#3a3a3a", "editorLineNumber.foreground": "#6a6a6a", "activityBar.background": "#252525" } }
