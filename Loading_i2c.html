📡 Индикатор активности шин

Три режима — один фреймворк. От ШИМ до виртуального ШИМ на любом таймере.

STM32 ESP32 AVR без HAL-блокировок ISR-safe

💡 1. Описание идеи

Мы строим индикатор интенсивности трафика на шинах (I2C, SPI, UART). Вместо дискретного «горит/не горит» светодиод плавно меняет яркость пропорционально частоте пакетов. При этом мы не используем внешние компоненты и не нагружаем основной поток выполнения.

  • Ядро идеи: В прерывании по завершению передачи (DMA или событие) мы считываем текущее значение счётчика таймера и корректируем параметры, управляющие светодиодом.
  • Логика изменения яркости: Если счётчик находится выше середины периода — активность высокая → яркость растёт. Если ниже — активность падает → яркость уменьшается.
  • Три режима работы: Аппаратный ШИМ, частотный метод, виртуальный ШИМ (одноканальный) — выбираются на этапе компиляции.
  • Фоновый режим: Весь код выполняется в прерываниях, не нагружая основной поток или FreeRTOS-задачи.
✅ Ключевое преимущество: Единая кодовая база под любую платформу и любые ресурсы — от AVR до ESP32.

⚙️ 2. Базовый алгоритм (платформонезависимый)

Ниже — общий псевдокод, который лежит в основе всех трёх режимов.

// Глобальные переменные (volatile, aligned)
volatile uint32_t brightness = 500;   // текущая яркость (0…65535)
const uint32_t STEP = 8;              // шаг изменения
const uint32_t MAX_BRIGHT = 60000;
const uint32_t MIN_BRIGHT = 100;

// ISR по завершению передачи (I2C/SPI/UART)
void Bus_Complete_ISR(void) {
    // 1. Фиксируем текущий счётчик таймера
    uint32_t cnt = TIMER->CNT;
    uint32_t half = TIMER->ARR / 2;

    // 2. Корректируем яркость
    if (cnt > half) {
        if (brightness < MAX_BRIGHT) brightness += STEP;
    } else {
        if (brightness > MIN_BRIGHT) brightness -= STEP;
    }

    // 3. Применяем новый параметр (зависит от режима)
    //    — для ШИМ: TIMER->CCR = brightness
    //    — для виртуального ШИМ: TIMER->ARR = brightness
    //    — для частотного: TIMER->ARR = brightness (меняется частота)
}

🎯 3. Три режима индикации

🔵 Режим А. Аппаратный ШИМ

Используется встроенный ШИМ-модуль таймера. Яркость управляется через регистр сравнения CCR. Частота фиксированная, скважность меняется.

  • Требования: Таймер с поддержкой ШИМ (канал сравнения).
  • Платформы: STM32 (TIMx), ESP32 (LEDC), AVR (Timer1 Fast PWM).
  • Преимущества: Максимальная точность, нет мерцания, минимальная нагрузка на CPU.
  • Недостатки: Требует ШИМ-периферии.
Пример кода: TIM2->CCR1 = brightness; — регистр сравнения обновляется в ISR.

🟢 Режим Б. Виртуальный ШИМ (одноканальный)

Ваш авторский метод. Используется один таймер без ШИМ-периферии. Светодиод переключается по переполнению таймера, а длительность «горящего» отрезка управляется через регистр ARR. Второй отрезок (пауза) — это разница между ARR и аппаратным максимумом счёта таймера.

  • Суть: ARR задаёт точку переключения. От 0 до ARR — горим, от ARR до 0xFFFF — не горим.
  • Требования: Любой таймер с возможностью переполнения и прерываниями.
  • Платформы: Все (STM32, ESP32, AVR, PIC).
  • Преимущества: Не требует ШИМ-периферии, работает на любом таймере, частота фиксированная (нет мерцания).
  • Недостатки: Ограничен разрядностью таймера (16 бит → 65535 уровней яркости).
✅ Идеальный выбор для AVR и для случаев, когда ШИМ-таймеры заняты.

🟡 Режим В. Частотный метод

Используется один таймер без ШИМ, но в отличие от режима Б, меняется не скважность, а частота переключения. При высокой активности светодиод мигает быстрее, при низкой — медленнее.

  • Требования: Любой таймер с переполнением.
  • Платформы: Все.
  • Преимущества: Не требует ШИМ, очень простой код.
  • Недостатки: На низких частотах заметно мерцание (можно убрать фильтром или ограничением частоты).
⚠️ Рекомендуется: Использовать только когда частота переключений гарантированно > 100 Гц, чтобы глаз не видел мерцания.

🔧 5. Реализация на платформах

🔵 STM32 (CubeIDE / HAL)

CMSIS регистровый доступ

Режим А (ШИМ):

// Глобальные переменные
volatile uint32_t led_brightness __attribute__((aligned(4))) = 500;

// Инициализация ШИМ (TIM2, канал 1)
void pwm_init(void) {
    RCC->APB1ENR |= RCC_APB1ENR_TIM2EN;
    RCC->AHB1ENR |= RCC_AHB1ENR_GPIOAEN;
    GPIOA->MODER   |= GPIO_MODER_MODER0_1;
    GPIOA->AFR[0]  |= (1 << 0);
    TIM2->PSC  = 8400 - 1;
    TIM2->ARR  = 1000 - 1;
    TIM2->CCMR1 = TIM_CCMR1_OC1M_1 | TIM_CCMR1_OC1M_2;
    TIM2->CCER  = TIM_CCER_CC1E;
    TIM2->CR1  |= TIM_CR1_CEN;
    TIM2->CCR1 = led_brightness;
}

// ISR по завершению I2C
void HAL_I2C_MasterTxCpltCallback(I2C_HandleTypeDef *hi2c) {
    uint32_t cnt = TIM2->CNT;
    if (cnt > 500) {
        if (led_brightness < 999) led_brightness += 8;
    } else {
        if (led_brightness > 0) led_brightness -= 8;
    }
    TIM2->CCR1 = led_brightness;
}

Режим Б (виртуальный ШИМ):

// Глобальные переменные
volatile uint32_t pwm_arr __attribute__((aligned(4))) = 30000;

// Инициализация таймера (без ШИМ)
void timer_init(void) {
    RCC->APB1ENR |= RCC_APB1ENR_TIM2EN;
    TIM2->PSC = 8400 - 1;
    TIM2->ARR = pwm_arr;
    TIM2->DIER |= TIM_DIER_UIE;
    TIM2->CR1 |= TIM_CR1_CEN;
    NVIC_EnableIRQ(TIM2_IRQn);
}

// ISR по переполнению (инвертируем светодиод)
void TIM2_IRQHandler(void) {
    if (TIM2->SR & TIM_SR_UIF) {
        TIM2->SR &= ~TIM_SR_UIF;
        HAL_GPIO_TogglePin(LED_GPIO_Port, LED_Pin);
    }
}

// ISR по завершению I2C
void HAL_I2C_MasterTxCpltCallback(I2C_HandleTypeDef *hi2c) {
    uint32_t cnt = TIM2->CNT;
    uint32_t half = TIM2->ARR >> 1;
    if (cnt > half) {
        if (pwm_arr < 60000) pwm_arr += 10;
    } else {
        if (pwm_arr > 100) pwm_arr -= 10;
    }
    TIM2->ARR = pwm_arr;
}

🟢 ESP32 (ESP‑IDF)

LEDC GPTimer ISR-safe

#include "driver/ledc.h"
#include "driver/gptimer.h"

volatile uint32_t led_brightness = 500;

// Режим А (LEDC)
void pwm_init(void) {
    ledc_timer_config_t tcfg = {
        .speed_mode = LEDC_LOW_SPEED_MODE,
        .timer_num = LEDC_TIMER_0,
        .freq_hz = 1000,
        .duty_resolution = LEDC_TIMER_10_BIT,
    };
    ledc_timer_config(&tcfg);
    ledc_channel_config_t ccfg = {
        .speed_mode = LEDC_LOW_SPEED_MODE,
        .channel = LEDC_CHANNEL_0,
        .timer_sel = LEDC_TIMER_0,
        .gpio_num = GPIO_NUM_2,
        .duty = led_brightness
    };
    ledc_channel_config(&ccfg);
}

// ISR по завершению I2C (вызов из драйвера)
void i2c_complete_isr(void *arg) {
    uint64_t cnt = 0;
    gptimer_get_raw_count(timer_handle, &cnt);
    if (cnt > 500000) {
        if (led_brightness < 1023) led_brightness += 8;
    } else {
        if (led_brightness > 0) led_brightness -= 8;
    }
    ledc_set_duty(LEDC_LOW_SPEED_MODE, LEDC_CHANNEL_0, led_brightness);
    ledc_update_duty(LEDC_LOW_SPEED_MODE, LEDC_CHANNEL_0);
}

🔴 AVR (avr‑libc)

Timer1 Fast PWM TWI

#include <avr/io.h>
#include <avr/interrupt.h>

volatile uint16_t led_brightness = 500;

// Режим А (Fast PWM)
void pwm_init(void) {
    DDRB |= (1 << PB1);
    TCCR1A = (1 << WGM10) | (1 << WGM11) | (1 << COM1A1);
    TCCR1B = (1 << WGM12) | (1 << CS10);
    OCR1A = led_brightness;
}

// ISR по завершению I2C
ISR(TWI_vect) {
    uint16_t cnt = TCNT1;
    if (cnt > 511) {
        if (led_brightness < 999) led_brightness += 8;
    } else {
        if (led_brightness > 0) led_brightness -= 8;
    }
    OCR1A = led_brightness;
}

⚙️ 6. Универсальный фреймворк (выбор режима)

В одном проекте можно поддерживать все три режима, выбирая нужный на этапе компиляции.

// ==============================================
//  ВЫБОР РЕЖИМА ИНДИКАЦИИ
// ==============================================
// Раскомментировать нужное:

// #define IND_MODE_PWM          // Режим А — аппаратный ШИМ
// #define IND_MODE_VIRTUAL_PWM  // Режим Б — виртуальный ШИМ (ARR)
// #define IND_MODE_FREQ         // Режим В — частотный метод

// Общий интерфейс
void indication_init(void) {
    #if defined(IND_MODE_PWM)
        pwm_init();
    #elif defined(IND_MODE_VIRTUAL_PWM)
        virtual_pwm_init();
    #elif defined(IND_MODE_FREQ)
        freq_init();
    #endif
}

void indication_on_activity(void) {
    #if defined(IND_MODE_PWM)
        pwm_update();
    #elif defined(IND_MODE_VIRTUAL_PWM)
        virtual_pwm_update();
    #elif defined(IND_MODE_FREQ)
        freq_update();
    #endif
}

⚠️ 7. Подводные камни

  • Выравнивание: На STM32 все 32-битные переменные, используемые в ISR, должны быть __attribute__((aligned(4))).
  • Атомарность: Запись в CCR или ARR атомарна, но операции brightness += STEP — нет. Используйте __disable_irq()/__enable_irq() на STM32 или portENTER_CRITICAL_ISR() на ESP32.
  • Приоритеты ISR: Всегда самый низкий приоритет, чтобы не мешать системным задачам (HAL, FreeRTOS, Wi-Fi).
  • Длительность ISR: Только чтение/запись регистров. Никаких printf, HAL_Delay, vTaskDelay.
  • Частота в режиме В: Убедитесь, что минимальная частота переключений > 100 Гц, чтобы избежать видимого мерцания.

📌 8. Итог

Мы построили универсальный фреймворк индикации активности шин, который:

  • Работает на STM32, ESP32, AVR и любых других МК с таймерами.
  • Поддерживает три режима: аппаратный ШИМ, виртуальный ШИМ (ваш авторский метод), частотный метод.
  • Выбирается на этапе компиляции через дефайны — одна кодовая база под любую задачу.
  • Не требует внешних компонентов, работает в фоне, не нагружая основной поток.
  • Масштабируется на несколько шин (I2C, SPI, UART) через отдельные светодиоды или мультиплексирование.
